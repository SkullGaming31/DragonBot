# Security Policy

## Supported Versions

Security updates are provided for the latest version of DragonBot on the
`master` branch. Older versions may not receive security fixes.

| Version | Supported |
| ------- | --------- |
| Latest `master` | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately by emailing
**skullgamingg31@gmail.com**. Do not open a public GitHub issue for a
suspected vulnerability.

When reporting, please include:

- A description of the vulnerability and its potential impact.
- The affected version or commit, if known.
- Steps to reproduce the issue and any relevant logs.
- Suggested mitigations, if available.

Please remove bot tokens, database credentials, API keys, and other sensitive
information from your report.

The maintainer will review reports and respond as soon as reasonably possible.
If the issue is confirmed, the maintainer will work on a fix and coordinate
disclosure. If it is not accepted as a vulnerability, the maintainer will
explain the decision where possible.

Please allow time for a fix before publicly disclosing the issue. Only test
against systems and Discord servers you own or have permission to test.
